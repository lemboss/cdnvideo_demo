# ADR 0002: Геокодинг через порт и Яндекс Геокодер

## Статус
Принято

## Контекст
При добавлении города клиент передает только название, а координаты нужно получить из внешнего сервиса.

## Решение
Доменный слой зависит от интерфейса `GeocodingClient`. Первая реализация использует Яндекс Геокодер:
`https://geocode-maps.yandex.ru/v1?apikey=key&geocode=city&lang=ru_RU&format=json`.

В ответе `Point.pos` парсится как `longitude latitude`. Если Яндекс вернул несколько результатов, используется первый.

## Последствия
Провайдера можно заменить без изменения бизнес-логики. Ошибки сети, пустой ответ и битый ответ возвращаются как управляемые ошибки.
