# ADR 0005: Стиль Python-кода и Ruff

## Статус
Принято

## Контекст
Сервис должен соответствовать PEP8, а проверки стиля должны быть быстрыми и одинаковыми локально и в CI.

## Решение
Используем Ruff как основной linter и formatter для Python-кода.

Ruff настроен в `pyproject.toml` для Python 3.13 с `line-length = 100`. Включены правила `E`, `F`, `I`, `UP`, `B`, `ASYNC`, чтобы проверять PEP8-совместимость, неиспользуемые импорты, порядок импортов, современные Python-паттерны, частые bug-prone конструкции и async-антипаттерны.

Основные команды:

```bash
./venv/bin/ruff format app tests
./venv/bin/ruff check app tests
./venv/bin/ruff check app tests --fix
```

## Последствия
Код форматируется единообразно и проверяется быстрее, чем отдельная связка Black, isort, pyflakes и flake8. CI должен запускать Ruff перед тестами, чтобы проблемы стиля и простые ошибки ловились до runtime-проверок.
