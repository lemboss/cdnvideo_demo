# ADR 0003: Идемпотентное добавление города

## Статус
Принято

## Контекст
Название города не является глобально уникальным, но текущий контракт принимает только название без дополнительных уточнений.

## Решение
В v1 считаем `normalized_name` уникальным ключом. Повторный `POST /cities` с тем же названием возвращает существующий город и не вызывает геокодер повторно.

## Последствия
API проще для клиентов и устойчив к ретраям. Для поддержки одноименных городов позже понадобится расширить контракт, например добавить страну или регион.
